# 分割模型对照协议

日期：2026年11月15日。本页保留正式启动前冻结的结构、配方与验证协议，实际已完成三种子8/20/13轮及完整终审；[实际结果与限制](step11_mature_results.md)另行记录，不回写修改冻结参数。本实验保留测试未访问。

## 比较问题与实现身份

本实验检验在同一项目数据、输入和共同优化配方下，成熟MobileNetV2–DeepLabv3+结构与已完成小型U-Net的分割表现及训练变异。它不是对两模型各自最优性能的比较：3e−4学习率先前通过U-Net pilot诊断选择，没有对新结构等额单独调参。不能把项目实现已有结构作为算法创新，也不在此阶段比较论文公开排行榜。

本机R2024b官方DeepLab整网入口缺少预训练骨干支持包，而公开`mobilenetv2('Weights','none')`能构造未训练图。本实验不下载预训练权重，采用公开无权重骨干，用公开MATLAB层API原创组装ASPP及解码器。实现明确称“成熟结构的本项目MATLAB实现”，不称MathWorks构造器或作者TensorFlow代码的逐位复现。

结构依据[DeepLabv3+原论文](https://arxiv.org/abs/1802.02611)、[作者模型实现](https://github.com/tensorflow/models/blob/master/research/deeplab/model.py)及[公共MobileNetV2接口](https://www.mathworks.com/help/deeplearning/ref/mobilenetv2.html)。模型配置为[mobilenet_deeplab_scratch_v1.json](../configs/mobilenet_deeplab_scratch_v1.json)，SHA-256为`22b7f339617b77dd2f62cd0c888c6ff81391d0b1e30b73dd8ab0bd3f15821435`。

## 冻结结构与已知限制

- 输入256×256×3、两类，仍只做一次single/255，输入层Normalization为none。
- 高层`block_16_project_BN`为16×16×320，低层`block_3_expand_relu`为64×64×144。最后一次stride2改为1，后续深度卷积膨胀2，输出步长16。
- ASPP由1×1、rates6/12/18的三个深度可分离分支和图像级池化组成，各投影256通道；拼接后投影256，dropout=0.1。
- 低层投影48通道，拼接上采样ASPP后使用两个3×3深度可分离/256块，输出2类logits并双线性上采样到原输入，再softmax。
- BN统一epsilon=1e−5、MeanDecay/VarianceDecay=0.1；保留公开无权重骨干原学习率因子，新头部因子1。实际构造的非1因子数为0；不会手工二次乘因子。
- bilinear插值显式采用R2024b公共层的half-pixel，作者TensorFlow代码的align_corners不同。端点、BN及可训练头部bias等属于项目明确设置。

16×16特征上rate18的3×3分支除中心外采样落在补零区，这是本输入几何的限制。外围核梯度为0属预期，不要求每一个参数的梯度均非零。本实验不因验证表现改变率或分辨率；若后续研究修改，另立版本。V排除补边损失和指标，但不代表补边不影响BN、卷积或全局池化。

实际总参数2,740,082，骨干1,827,488、头部912,594，65个BN层、198层。约为482,050参数小U-Net的5.68倍。2026年11月15日仅更正原“约多”的倍数表述，依据2740082/482050≈5.6842，参数和配置均未改变。MobileNet骨干的名称不能用来预设整网比本项目小U-Net更小或更快。

## 工程预检查及失败保留

`mature_contract_v1_01`在构造阶段因R2024b不支持将`NumChannelsPerGroup`传为grouped convolution构造参数而失败，原图0、更新0。修正为公开层自动推断通道，没有改变结构、学习率或样本，另用新run运行，原失败及源文件快照保留。

`mature_contract_v1_02`通过：种子14/15/16/14从头构造，前后14指纹相同、前三种子不同；BN初始均值0、方差1。高低层及两类输出形状正确；概率通道和、损失概率及batch1/2推断误差均约5.96e−8。只读取既有固定8张训练图，不读验证或测试。

一次性网络实际做5次工程更新：batch8的1次预热＋3次计时，以及1次batch4尾批检查。骨干和头部均有有限有效参数变化，BN State有限且实际变化。保存重载的预测误差0。追加后检不读原图、不更新优化器，核实65个TrainedMean和65个TrainedVariance、初始状态与指纹、completed5/next6及配置SHA，并再次确认predict不变更State或RNG。没有据此声称完成一次中断后优化器步骤重放。

本机Adam纯合成因子0/1/2实测也通过：`adamupdate(net,...)`按有效LR应用因子，裸参数表行为不同，因此复用现有网络对象更新方式。[Adam接口](https://www.mathworks.com/help/deeplearning/ref/adamupdate.html)第一版合成探测的单复数属性拼写错误、0更新失败也保留。

81份工程元数据、日志和项目原创源快照的原字节副本见工程证据索引。预检网络及其权重留在本地，正式训练全部从头开始，不读取这5次更新后的权重。

## 计算成本与保存安排

同一CPU/single/最大计算线程16环境，batch8的3次稳态更新为3.6224814、3.0097624、2.9129551秒，中位3.0097624秒；首步预热12.488272秒，尾批4图检查约5.237秒。计时是训练更新，不能换算成推理或巡检FPS。

按中位数粗估，三个种子20轮上限的纯更新为31602.5052秒，约8.78小时；数据加载、初始化、400图逐轮验证、保存/重载、日志及绘图另计。早停可能减少实际成本，不能预保证结束时间。维持三个种子的决定在查看新结构验证结果之前固定。

原工程检查总墙钟6657.055秒，其中两个种子配置生成时间之间存在约110分钟未细分空档，现有证据不能确认原因，不把该空档擅自归为模型运算或系统休眠。追加同构造的实测墙钟16.137秒、CPU14.203秒。正式runner额外记录构造CPU/墙钟及各runCPU/墙钟，实测优先于外推。
