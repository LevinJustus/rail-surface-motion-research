# 实拍连续视频上的 DeepLab 前端与条件融合

2026 年 11 月 24 日。实验使用三段未标注的钢轨连续视频，研究分割响应和时序融合行为。

## 实验设置

固定三个原速率片段各 180 帧，采样约 59.94 Hz。每帧复用固定 320×320 原图轨头裁剪，双线性抗混叠缩放至 256×256。三段分别重置历史。第三段另以约 29.97 Hz 取原本的 90 个偶数目标帧，再单独重置历史。两种速率的偶数目标帧共享同一个单帧概率文件。原速率组的位移仍连接原始相邻帧。

复用验证选点的 MobileNetV2–DeepLabv3+ 种子 20261114 权重，比较同一份原始概率下的单帧、v3 基础保守融合 B 和条件纠错 v3。三组共用固定 0.50 判定阈值。融合复用冻结的 RGB 估计位移、最多三帧的因果窗口及已有默认设置。条件纠错记录由保守值改写成强融合值的像素以及实际新增前景。相同输入下既有 Small U-Net 单帧与 B 作为前端对照。

## 前景响应与条件触发

| 片段与速率 | Small U-Net 单帧前景 | DeepLab 单帧前景 | DeepLab B 前景 | DeepLab 条件 v3 前景 | 条件写入 / 相对 B 新增前景 |
|---|---:|---:|---:|---:|---:|
| A，59.94 Hz | 99.50% | 5.92% | 4.83% | 4.96% | 22833 / 14980 |
| B，59.94 Hz | 98.84% | 12.99% | 12.03% | 12.27% | 41933 / 28384 |
| C，59.94 Hz | 81.59% | 24.91% | 24.78% | 25.07% | 56047 / 35050 |
| C，29.97 Hz | 81.59% | 25.09% | 25.01% | 25.26% | 22397 / 14593 |

三段原速率合计 540 帧。DeepLab 单帧、B 和条件 v3 的前景占比分别为 14.61%、13.88%、14.10%。B 相对单帧新增 240300、移除 498248 个前景像素观测。条件 v3 相对单帧新增 318714、移除 498248。条件 v3 相对 B 新增 78414、移除 0，占三段 ROI 的 0.222 个百分点。这里的计数为逐帧像素观测，同一物理位置可重复计入。

原速率下，534 个具备两条可用历史边的目标中，531 帧发生条件写入，528 帧出现相对 B 的阈值翻转。共写入 120813 个概率值，其中 78414 个形成新前景，其余位置已在 B 中达到阈值。条件触发在帧级很常见，改动面积较小。示例中新增像素分布在斑点纹理边缘和可见锈色带附近。这些位置的类别仍待核实。

## 配准拒绝与回退

三个原速率片段各 179 对，估计位移均未触边。片段 C 隔帧后，89 对中 13 对触及搜索边界并被拒绝，对应两种融合概率逐值回退至单帧。在相同 89 个非起始的偶数目标上，原速率相邻边 0 对被拒绝。相同的 90 个目标中，原速率条件分支相对 B 新增 15950 个前景像素观测，隔帧新增 14593 个。配对目标相同，历史间隔和位移候选不同。

## 核验与适用范围

540 次 CPU 前向，零优化更新。冻结检查点和网络状态通过核验。此前同检查点运行的 12 张取帧，输入与单帧概率均逐值复现。630 个目标的计数与 1260 份融合概率、630 张触发掩膜通过复核。另从完整流式 v3 入口重放 214 个目标，位移和 B 概率一致。17 个回退或起始重置逐值一致。90 个偶数目标的输入映射通过复核。

当前缺少独立确认的缺陷标注和位移真值。结果支持配对比较前景响应、实际触发和回退行为。检测收益、配准精度和实测系统吞吐仍需相应证据。下一步固定 DeepLab 前端，在独立确认的正常锈色、其他外观纹理及真实缺陷片段中分别评估新增与移除，再判断条件纠错是否值得保留。附表按匿名片段、比较范围、模型和方法报告原始计数，隔帧匹配行属于同一批目标的子集。
