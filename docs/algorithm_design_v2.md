# v2：运动不确定性驱动的缺陷证据补偿

日期：2026年11月18日。本文给出v2运动不确定性驱动的概率补偿设计，配套[实现与解析检查](algorithm_v2_minimal_results.md)、[训练来源诊断](step13e3_training_diagnostic_results.md)及[冲突项消融](step13e4_conflict_ablation_results.md)。

## 1. 本次确定的主线

核心问题：配准给出的一个最优位移，不足以说明历史缺陷概率可以安全搬到当前帧。轨面重复纹理可能对应多个合理位移；不同补偿结果对细小缺陷的影响也不同。

本版本围绕一个候选机制展开：**将运动匹配的歧义、候选截断和视野损失传递到像素级缺陷证据，再根据补偿风险决定历史更新幅度。** 轻量分割网络继续提供原始概率，不作为主要创新；运动约束、有限窗口和当前证据保护为该机制提供输入条件与行为约束，不分别包装成多个创新点。

整体流程：当前图像与原始分割概率 → 视觉/观测运动候选权重 → 多位移补偿 → 像素级补偿风险 → 有限历史证据更新 → 缺陷概率/掩膜及诊断输出。

## 2. 输入、状态和范围

输入为当前RGB图像I_t、原始缺陷概率p_t、时间戳及可缺失的观测里程。编码器尚未实测，目前只能使用模拟观测运动。保留当前帧及最多两帧原始历史，不把已经融合的概率递归存回历史，也不访问未来帧。

首版仍用256×256输入、平移运动模型和小型U-Net；网络固定，避免同时改网络与补偿机制。旋转/视差残差属于模型限制，由失败诊断和后续数据决定是否另立版本，不在本版堆叠更多运动模型。无标定时输出像素坐标，不输出毫米或每米误报。

## 3. 运动候选及其权重

在固定[-20,20]²整数位移域D上计算与v1一致的NCC分数ρ(d)。定义视觉权重：

\[
v(d)=\frac{\exp((\rho(d)-\rho_{\max})/T)}{\sum_{u\in D}\exp((\rho(u)-\rho_{\max})/T)}.
\]

模板标准差低于1e-6、非有限匹配、最大NCC低于0.2或视觉最大值落在搜索域边界时拒绝该历史，回退当前帧；不能把平坦相关图归一化后冒充可靠运动。这里的权重是启发式匹配分布，未经校准，不能称为真实运动后验或95%置信度。

有效观测增量Δo对应d_o=(0,-Δo)。令G(d)为在同一有限域归一化的二维高斯，初始协方差为diag(4,4)像素²。令d_v为纯视觉整数最大值，

\[
r_o=\frac{1}{1+\|d_v-d_o\|^2/8},\quad
a(d)=r_oG(d)+(1-r_o)/|D|,\quad
w(d)=\frac{v(d)a(d)}{\sum_{u\in D}v(u)a(u)}.
\]

观测缺失、非有限或超出固定运动范围时r_o=0，所以w=v；视觉与里程明显冲突时先验趋向平坦，不强迫视觉服从错误里程。该规则不是先验正确性的保证；重复纹理下视觉峰和错误里程仍可能共同指向错误位置。

按w从大到小保留候选，累计质量达到0.95或最多25个即停止；并列按dy、dx确定顺序。**截断后不重新归一化原权重**，剩余质量必须继续进入风险。首个实现采用整数候选；v1亚像素单点作为强参照保留，不能把插值精度差异归给不确定性机制。亚像素多候选另版本研究。

两帧以上历史通过相邻运动组合到当前坐标：路径位移求和，权重相乘，再按相同预算保留；不对截断路径重新归一化。路径任何中间时刻越界均视为该像素未知，避免只看最终落点。

## 4. 从位移歧义到缺陷补偿风险——核心候选

对历史帧i的保留路径k，记原始权重为w_ik，当前像素的有效标志为V_ik(x)，补偿概率为h_ik(x)。定义已知质量和条件历史均值：

\[
q_i(x)=\sum_k w_{ik}V_{ik}(x),\qquad
\bar h_i(x)=\frac{\sum_k w_{ik}V_{ik}(x)h_{ik}(x)}{q_i(x)}.
\]

q=0直接拒绝该历史，不作除法。截断、无覆盖和中间越界造成的质量都计入1-q，不当成确定背景。

以当前概率p=p_t(x)为参照，计算：

\[
R_i(x)=\sum_k w_{ik}V_{ik}(x)(h_{ik}(x)-p)^2
 +(1-q_i(x))\max\{p^2,(1-p)^2\}.
\]

已知部分同时包含多候选补偿之间的分歧和历史/当前冲突，因为其等于q_i[Var(h_i)+(\bar h_i-p)²]。未知部分按[0,1]范围内最坏平方差计入，避免只保留少数候选后出现虚假的高置信。

该式是**在所定义离散权重模型下，对遗漏概率值与当前预测平方差的代数上界**，不是对真实标签错误率的上界，也不保证运动权重经过统计校准。若候选域遗漏真实运动，整个模型仍可能自信但错误。

## 5. 融合、回退与当前证据保护

初始可靠系数只用上述风险：

\[
g_i(x)=q_i(x)\exp[-R_i(x)/(2\sigma_R^2)],\qquad
\Delta(x)=\frac{1}{n}\sum_{i<t}g_i(x)(\bar h_i(x)-p_t(x)),
\]

其中n为实际到达窗口长度（1—3），σ_R初值0.25。没有历史或全部拒绝时Δ=0；更新为凸组合，不引入新网络或额外的熵/光度门控堆叠。

统一主阈值τ=0.5。当当前p≥0.7时，限制负向总更新不得小于τ-p：

\[
\Delta^*(x)=\max\{\Delta(x),\tau-p_t(x)\};
\]

其余像素Δ*=Δ，最终p_out=clip(p+Δ*,0,1)。该规则只保护当前强前景像素在固定“≥τ”判定下不被历史翻为背景；**不保证真实缺陷都被发现，也可能保留错误前景、增加误报或妨碍纠错。** 这是明确的设计约束，不能将其带来的机械召回保护单独宣称为创新。

## 6. 本版和原v1的实质区别

| 部分 | v1 | 候选v2 |
|---|---|---|
| 运动表示 | 单个最优亚像素位移 | 有限域多候选权重，显式保留截断质量 |
| 可靠性 | NCC/循环/光度/熵因子相乘 | 多补偿结果对缺陷概率的分歧和冲突，遗漏质量按最坏平方差处理 |
| 历史缺失/越界 | 无效历史回退 | 回退，同时把损失的运动质量带入像素风险 |
| 状态 | 有限原始窗口及递归对照 | 主方法固定有限原始窗口，不递归污染状态 |
| 强当前前景 | 没有该约束 | 限制历史负向翻转，单独消融并报告误报代价 |

## 7. 创新定位与必须承认的前作

运动不确定性、多假设和概率传播本身都有前作，不主张首创。原13C1已经核查GRFP等概率传播/门控方法；本次有界补查又确认[PDC-Net（CVPR 2021）](https://openaccess.thecvf.com/content/CVPR2021/papers/Truong_Learning_Accurate_Dense_Correspondences_and_When_To_Trust_Them_CVPR_2021_paper.pdf)研究运动对应及其不确定性，[MHP-VOS（CVPR 2019）](https://openaccess.thecvf.com/content_CVPR_2019/html/Xu_MHP-VOS_Multiple_Hypotheses_Propagation_for_Video_Object_Segmentation_CVPR_2019_paper.html)使用多假设传播。两者本次仅核查官方条目/摘要，不以未读完整细节证明本方法独有。

需要进一步查重和验证的具体候选，是**将截断运动候选及视野未知质量，以显式风险传递到小缺陷概率更新**，并检验其是否优于单点补偿、通用门控和简单少用历史。公式写得完整不等于新颖性成立；若相关方法已有同等机制，应据实调整贡献。

## 8. 接下来的最短验证路径

1. 实现最小核心和解析契约：权重、路径组合、遗漏质量风险、越界、首帧、缺测与强前景约束。先证明程序符合本设计。
2. 固定一个检查点、最多12条训练来源序列，做小样本否证筛查；不先铺开三种子全矩阵。重点检查相对单点补偿是否只是普遍关闭历史。
3. 原理和小样本检查通过后，才冻结正式比较预算。最低消融为：单点/多候选、丢弃/保留剩余质量、不保护/保护强当前前景；保留S、v1强视觉门控和恒定衰减参照。
4. 正式实验检验检测净收益、新增漏检/误报、运动歧义分层及实际耗时。若无收益或只有退回S的保护，不将其写成有效创新。

v2的默认更新幅度、强前景保护和严重漏检恢复限制见[实现分析](algorithm_v2_minimal_results.md)。同输入诊断与单因素消融分别记录，原C5批次状态及后续反馈方法见[研究进展](PROGRESS.md)。
