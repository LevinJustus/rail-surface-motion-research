# 因果多帧融合实验协议

冻结日期：2026年11月18日。状态：协议设计与静态核验；尚未实现或运行融合。配置为[fusion_protocol_v1.json](../configs/fusion_protocol_v1.json)，SHA旁文件及冻结清单记录实际字节。改变方法、参数、名单、指标或比较顺序须新版本，不覆盖v1。此为项目内部预先冻结，不是外部注册平台预注册。

## 1. 研究问题与证据边界

本阶段固定分割器，分别检验补偿、观测先验与历史可靠性的贡献。依据[13C1近邻核查](step13c1_literature_results.md)，概率传播、置信度加权和递归误差控制已有直接前作；以下公式是待验证的独立机制实现，不声称复现GRFP/Deka成绩或已经具有新颖性。

- H1：视觉补偿固定融合V相对未对齐平均U、同输入单帧S是否同时改善缺陷IoU。仅V优于U而不优于S，不足以说明融合值得采用。
- H2：先验辅助配准固定融合P相对V是否有额外收益。13B两种配准逐对相同，v1预计仍可能完全一致；这种结果须报告为没有额外证据。
- H3：在相同视觉位移与视觉门控下，加入观测位移不一致衰减GVP，是否比纯视觉门控GV减少新增错误并改善检测。另设GC恒定衰减，防止将“少用历史”误认成识别坏历史的能力。

v1是保守的可证伪候选，不是承诺最终采用的算法。纵向不一致不能判定究竟是视觉错还是模拟里程错，衰减可能抹去有用历史；横向振动也不能直接归罪于一维里程。全文缺口继续按13C1记录，不能用本协议填补新颖性证据。

## 2. 冻结数据、模型与开发预算

采用step12_full_v2_01原生256×256 RGB裁剪序列，9帧/序列，间隔0.05秒。训练来源契约及校准使用13B同样的3个训练来源、36序列/324帧；正式验证为15个验证来源、180序列/1620帧。名单由冻结sequence_index逐条核对，训练与验证来源/代理组无交叉；每来源12条件等权保留，包括空掩膜、缺测及退化条件。准确映射和掩膜不进入算法。

仅使用Small U-Net已有best_validation检查点，初始化种子20261114、20261115、20261116，分别来自第8、6、7轮；不重新挑模型、不使用last替代差种子、不优化网络。配置记录文件与参数SHA。检查点本身曾由静态验证选出，因此本实验仍属于开发验证，不能宣称独立最终测试。DeepLab扩展须另立事项，不在v1混入。

图像输入严格为uint8 RGB转single/255，256×256，不缩放、不补边、不重新使用带标签的read_segmentation_sample入口；predict模式，通道background/defect，取第2通道。记录网络参数、状态和检查点前后SHA。每帧只推理一次，全部方法共用同一原始概率缓存；不复用13A整图缩放概率。缓存为小端float32、256×256列主序，记录图像/概率SHA、网络和预处理版本。逐帧输出以float32落盘后再评价；预测阶段只用未经融合的历史概率作为缓存观测。

13C3先按首种子完成解析检查，再运行全部36训练序列；C4前允许另外两个预定种子的同36训练序列校准。总计3×324=972次训练来源单帧推理、3×1620=4860次正式验证推理；共5832次唯一图像-检查点前向，不含明示的工程重载/复放核验。8方法×3种子×180序列×9帧=38880个验证方法帧输出，其中主比较为帧2—9的34560个输出，不是独立样本数或性能结果。

窗口、门控及压力水平采用下文固定工程常数，本实验没有依据融合成绩调参。门控参数搜索预算为0；阈值校准仅按第7节19点规则。工程错误可在训练来源契约内修正，保留失败和修订；改变科学假设/参数另建v2。任何正式验证分割结果打开后，不再回调v1参数。13B 的几何结果属于已有的开发证据。

## 3. 因果时间、配准与采样

主窗口W=3，即当前帧和至多两帧过去原始观测，零未来等待。每序列独立重置，禁止跨序列状态；主方法不递归使用上一融合结果。首帧原样输出S；帧2采用一帧历史，帧3起采用两帧历史。主表评价帧2—9；帧1—9及满窗口帧3—9作为固定辅助表，不根据结果选择。

每条相邻边使用13B同样的128中心模板、±20整数全局NCC、±4先验窗口、0.2最低相关、±0.5亚像素。前向平移d=(dx,dy)表示历史像素在后帧的位置x_t=x_j+d。两帧历史位移为沿相邻边求和，不重新用里程相减填补缺边，不用准确变换；累计位移不再裁回±20。反向NCC独立交换两幅已到达图像，仅供视觉可靠性，不访问下一帧。观察里程仅当边两端均可用且增量绝对值≤20时有效，正增量对应dy=-delta；缺失/超界时先验NCC回退视觉，门控先验因子回到1并记录缺失，不能假装确定零位移。

算法新辅助接口须共享同一前向完整相关图供V/P及诊断使用，每边另算一张反向图；不得为候选额外扩大搜索或重选真值附近峰。C3需与冻结register_motion_pair.m的训练来源前向V/P结果逐项核对，原13B源码不修改。若工程实现确有重复计算，记录实际次数与耗时，不凭目标预算声称加速。S/U不需要NCC；V/P不需要反向图，其独立运行代价与全方法共享实验代价分别记录。

后向采样明确为q=x_t-d，x是列、y是行，坐标均为1基。对概率和灰度作双线性插值，原始有效域为[1,256]²；闭区间边缘按边界像素退化权重处理，出域位置有效位为0，数值占位不得当确定背景参与融合。两边组合历史除最终q在域内，还须经过的中间坐标也在域内，且各边估计可用。先合成平移后从原始历史采样一次，避免两次插值；两跳路径有效位按所有经过视图判断。不得用几何真值定义算法有效位。

算法只读当前帧及已到达历史，不能预读motion_input的未来元素作决策。离线预生成的独立逐帧缓存允许存在，但C3必须用前缀重放、修改未来帧和未来里程不改变既往输出证明因果性。全输入文件哈希可由独立审计进程核对，其访问不得混入算法访问记录。非递增时间戳/尺寸变更拒绝运行；大于0.075秒的时间间隔清空历史并记录重置，反向和停车本身不重置。

## 4. 八个预定对照与融合式

令p_t为当前原始前景概率，K=min(2,t-1)，w=1/(K+1)，h_j为采样后的历史概率，v_j为路径覆盖位，g_j∈[0,1]。主融合统一为：

`f_t = p_t + w * sum_j [v_j * g_j * (h_j - p_t)]`。

没有历史时f=p。无效或被拒绝历史的权重回给当前帧；不在剩余历史间重新归一化。全部有效且g=1时为等权平均，门控衰减后当前权重至少1/(K+1)。所有计算用double，检查有界/有限，落盘single；超出[0,1]超过1e-6算错误，只有数值级偏差可截断。拒绝回退只保证相应历史不参与，不保证接受历史不会新增漏检。

| ID | 方法 | 固定设置与用途 |
|---|---|---|
| S | 同输入单帧 | f=p，无配准或历史；主阈值和校准阈值都保留 |
| U | 未对齐时间平均 | 同一像素坐标原始概率，v=1，g=1；与V使用相同窗口和均值权重 |
| V | 视觉补偿固定融合 | 视觉NCC，g=1，按覆盖位回退；检验补偿贡献 |
| P | 先验NCC固定融合 | 13B先验窗口/缺测回退，g=1；与V比较H2 |
| GV | 纯视觉可靠性融合 | 与V完全相同位移，采用第5节g_visual；强视觉机制对照，不称最优已有方法 |
| GVP | 观测不一致候选 | 与GV完全相同位移，仅乘第6节g_odom；检验额外运动信息，不混入换配准的影响 |
| GC | 恒定衰减控制 | 与GV相同，g=g_visual×c_train；区分降低历史总量和识别不一致 |
| R | 有限递归视觉机制参照 | 同样只用当前及前2帧，按下述有界两跳递归；项目对概率平滑机制的独立改编 |

R每次从窗口最旧原始概率重新初始化，不携带窗口外融合状态。先在t-1坐标以0.5混合p_(t-1)和p_(t-2)的视觉warp，采用第5节视觉门控；再以0.5混合p_t和该中间状态的单跳warp，熵因子使用实际中间概率，图像残差使用对应原始RGB。每次越界/不可用部分回到该步当前概率。帧2只做后一单跳，帧1原样。其三帧权重不同于等权主式，结果单列，不能把差异全部归于递归。不限长度的递归另为C5失效诊断。

## 5. 纯视觉门控的具体定义

灰度沿用13B权重0.2989/0.5870/0.1140并除255，范围[0,1]。下列参数均为冻结工程尺度，不是从结果估计的最优值。

每条视觉边e记录前/后向可用性、相关峰s、全局搜索边界及第二峰s2。s2为±20全图候选中排除选中整数峰Chebyshev距离≤2区域后的最高值；没有剩余候选或任意非有限量则质量为0。反向也按同规则计算。边界峰或任一方向不可用时Q_e=0；否则：

`a_e = min(clip((s_f-0.2)/0.6), clip((s_b-0.2)/0.6))`；
`b_e = min(clip((s_f-s2_f)/0.05), clip((s_b-s2_b)/0.05))`；
`c_e = exp(-||d_f+d_b||²/(2*1.0²))`；`Q_e=a_e*b_e*c_e`。

clip指截到[0,1]。二峰差小可能拒绝正常周期纹理；此限制保留，不按验证选择取消。路径质量Q为经过边Q_e的乘积，仅用于GV/GVP/GC/R，不额外让V/P采用门控拒绝。

历史灰度一次warp到当前后，计算绝对灰度残差的5×5有效邻域均值r(x)，仅纳入路径有效位置，图像边界截取真实邻域，不零填补统计；无有效邻域时拒绝。`g_photo=exp(-r²/(2*0.10²))`。不拟合标签驱动光照模型。

`C(p)=1-[-p log2(p)-(1-p)log2(1-p)]`，0log0按0。`g_conf=clip(2*(0.05+C(h))/(0.10+C(h)+C(p_t)))`。最终`g_visual=Q*g_photo*g_conf`。熵只描述概率尖锐程度，绝非预测正确率；置信错误仍可能通过门控，需实际统计损伤。所有门控都不知道掩膜、缺陷类别、条件名、准确几何或评价误差。

## 6. 观测运动因子与恒定衰减

每条边观测可用时，`z_e=exp(-(dy_visual+delta_observed)²/(2*2.0²))`，单位为像素。只比较纵向，不将未知横向里程设为零来惩罚横向视觉移动。观测缺失/超范围时z_e=1并记录fallback，不因此抛弃本来可用的视觉历史。路径`g_odom=product(z_e)`，GVP使用`g_visual*g_odom`，不依据不一致改写配准位置。

GC的c_train在36训练序列上、与正式窗口相同的所有历史路径计算g_odom后作算术平均；路径须视觉前向可用且路径里至少有一条可用观测边，不用掩膜或门控成绩筛选。无符合路径则c_train=1并明确空样本。该常数跨种子共享、C4前保存SHA冻结；缺失边在路径积中仍为1。GC使用这一常数乘全部g_visual，不能借验证拟合平均权重。恒定衰减只能排查部分混淆，不能自动证明GVP独有机制。

## 7. 评价、阈值和失败处理

主评价阈值对所有方法均为0.5，`probability>=threshold`判前景；无形态学后处理、无最小面积过滤。主有效域为当前图像的全部256×256像素，方法覆盖失败不能缩小分母。主表帧2—9，另表全9帧及帧3—9。评价掩膜来自已审计序列中心时刻二值GT，不从模糊图或融合图重标。

对每方法每种子在36训练来源序列的帧2—9独立计算阈值0.05至0.95（步长0.05）的来源宏IoU，选择最大者；1e-12内并列时先离0.5最近，再选较高阈值。该校准只在训练来源，是训练内阈值参照，不证明外推最优。所有8方法享同19点预算，单帧S不会只有默认阈值。阈值表和c_train先冻结再开启正式验证GT；正式验证只评价0.5和已冻结训练阈值，不选择验证最优阈值，也不沿用13A静态验证最优点。

主指标为等来源宏前景IoU：每个来源先汇总12条件×8帧TP/FP/FN/TN，再计算IoU；三种子分别报告，并先在同来源内平均3种子后取15来源均值。另报全局micro IoU、Dice、Precision、Recall、FN/GT、FP/背景、各条件与种子结果。IoU/Dice分母为0且空预测正确时记1，单列这种来源数及非空来源敏感性；Precision无预测、Recall无GT均记NA并给有效分母，不暗置0或100%。不以背景Accuracy或mIoU名称替代前景IoU。

每方法相对S在相同阈值0.5及全评价域统计FN→TP、FP→TN、TP→FN、TN→FP，保存四类掩膜计数，不给算法使用。新增漏检率=TP→FN/GT前景，新误报率=TN→FP/GT背景；纠正率对应前两类。恒等式：FN_method=FN_S−FN→TP+TP→FN，FP同理；须全部行核对。不同方法各自校准阈值下的变化不作纯融合损伤归因。

区域辅助指标：GT/预测均8连通，不删除小区域；GT组件被覆盖比例≥0.25视为该帧组件检出，按面积1—15、16—63、64—255、≥256像素分层。预测组件与全部GT组件最大IoU<0.1记未匹配误报；无GT时所有预测组件均记误报。报告每帧误报组件，不称物理缺陷事件、重复计数率、每米误报或细裂纹真实尺寸；此规则不是实例一一匹配指标，碎裂/合并局限明示。

不可用配准、缺测观测、越界历史或门控为0按上述局部回退，保存原因/覆盖率/权重，不删难帧。非有限概率、缓存不匹配、帧顺序错误或文件损坏属于运行失败：中止该run、保存错误，不用伪造单帧输出补齐；修复后新run ID。C4未完整执行8方法×3种子×180序列时不得作完整验证。

## 8. 配对不确定性与预定比较

独立统计单位为15个验证来源代理组，不能将1440相邻对、派生帧、条件或3次初始化当作新增物理样本。配对bootstrap固定PCG64种子20261118、10000次，每次有放回抽15个来源，保留每来源全部条件/帧和3种子，取来源内种子平均后计算差值；百分位95%区间，线性分位插值。空分母按第7节保留NA与有效数，各方法采用相同的该指标有定义来源掩码；每次抽样对有定义来源取均值，全为NA的重复单列，有定义重复少于9500次则不生成该指标区间或据其判断支持。不能静默换样本单位。仅表达这批来源的开发不确定性，不能修复未知物理轨段相关性。

主比较预定为V−U、V−S（H1），P−V（H2），GVP−GV及GVP−GC（H3/衰减混淆）；GV−V为通用门控辅助，R单列机制参照。每对同时报告ΔIoU及新增漏检/误报差值、来源胜/平/负，不只报最好条件/种子。区间为描述性，未作多重检验校正，不据多个区间挑“显著”。

描述性判断规则预先确定：H1需V−U与V−S的IoU差95%区间下界均>0；H2需P−V的IoU差下界>0，若逐输出相同直接记无额外证据。H3完整支持需GVP相对GV与GC的IoU差下界均>0、两类合计新增错误率差上界均<0，并且新增漏检率差与新误报率差各自上界均≤0。后两类分母是GT前景/背景，与合计分母分别计算；无GT的来源不虚构新增漏检率，报告有效来源数。仅减损无IoU收益记取舍，不能称检测提升；个别类损伤增加只能作局部现象。区间跨0或种子方向不一致按C6披露为证据不足/不稳定，不凭聚合区间掩盖种子差异。不强设达到多少百分点就算创新；上述未校正描述性规则不是多重检验后的确认性显著结论，任何支持仍不等于新颖性或真实视频验证。

## 9. C3契约和C5预定扩展

C3须检查：整数/亚像素位移方向与行列；停车/反向；双跳合成且仅插值一次；首帧和窗口满/不满；全/部分越界与路径中间越界；不可用边；缺失/超界观测；对齐失败；熵0/1/0.5；相同概率不漂移；门控0精确回退；未来输入扰动不影响过去；跨序列/间隔重置；原始和融合缓存隔离；坏历史1-p不产生非有限值；训练校准与评价身份隔离；独立计数恒等式。契约的手工/解析真值只在检查程序，不进入生产算法。C2静态核验不代表这些契约已经通过。

C5在本协议提前固定：窗口1和5敏感性（S/V/GV/GVP，原始历史，其他常数不变）；GV去掉photo、confidence、cycle、peak-margin的单项消融；GVP换先验NCC位移的交互消融；不限长度递归R对照有界R的累积诊断。不同窗口/递归代价分别披露，不合并到主表。

观测压力在同一训练/验证来源、全部12原条件上成对派生，不改RGB/掩膜或13B原记录：对可用绝对观测o_k加入b*(k−1)，b∈{-6,-2,2,6}像素/帧；加入A*(-1)^(k−1)，A∈{1,3}像素；另做所有观测不可用。每个变体单独施加，共7个观测压力版本，保留原缺失位，先在训练来源生成/验证；验证不按成绩挑条件。校准常数和阈值沿用原条件，不在压力数据重新拟合。

历史污染诊断另对所有方法共用的第3帧原始概率作1-p替换，其他帧不变，使用原RGB/位移；S在该帧也接收同一受损概率，后续帧原始概率恢复。报告帧4—9与无污染版本差异及实际窗口恢复时刻，不声称真实缺陷/分割器自然错误分布。该故障注入不用于选择门控，只评价传播；短窗口最终摆脱注入不单独构成创新。新增RGB/几何退化必须另版本，而非事后制造有利难例。

## 10. 证据交付与实验范围

计划配置分开列inference、开发校准、评价参数；算法入口仅接收inference白名单、模型/当前中性输入，不接收评价源ID、profile或GT路径。算法与评价分进程、预测及输入访问日志落盘并SHA冻结后才打开验证真值；这是接口/进程约束，不宣称操作系统权限完全隔离。

C4应交付原始/融合概率缓存索引、配置/源码/检查点/输入SHA、配准与门控逐边/逐路径诊断、阈值和c_train冻结表、逐帧/来源/条件计数、转换恒等式、bootstrap索引与汇总CSV。独立Python读取落盘概率重算全部主计数，并按固定名单抽训练首来源各条件第2及第6帧、验证首来源各条件第2及第6帧核查采样与门控；若独立实现不等价则不验证。

本协议定义融合对照、因果窗口、训练校准和评价规则。实现与开发验证分别见[融合实现](step13c3_implementation_results.md)和[验证结果](step13c4_validation_results.md)。缓存比较耗时与完整系统延迟分别记录。
