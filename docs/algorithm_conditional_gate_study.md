# 条件式历史纠错与对齐诊断

本实验比较单帧分割、v3 保守融合 B、强融合 E，以及三版条件式历史纠错。这里的「条件 v3」是融合消融版本，基础配准仍使用既有运动反馈原型的同一基础位移。实验冻结前端原始概率、三帧窗口、`0.5` 判定阈值及当前高置信前景保护。

## 对齐与历史传播

评估使用 3 个训练来源代理组的 12 条同图派生序列。108 帧中，去掉每条首帧后汇总 96 帧。真值几何只在单独的诊断中把历史原始概率采样到当前帧，沿途视野越界的历史像素不参与融合。保守冲突权重、强融合权重和保护规则在估计对齐与真值对齐下相同。

| 对齐与融合 | 漏检像素 | 误报像素 | 恢复单帧漏检 | 新增漏检 | 纠正单帧误报 | 新增误报 |
|---|---:|---:|---:|---:|---:|---:|
| 估计 B | 685,515 | 1,013,299 | 3,978 | 3,897 | 9,983 | 8,715 |
| 真值 B | 685,705 | 1,013,086 | 3,901 | 4,010 | 10,086 | 8,605 |
| 估计 E | 681,680 | 1,025,950 | 13,308 | 9,392 | 24,087 | 35,470 |
| 真值 E | 682,389 | 1,025,126 | 12,497 | 9,290 | 23,599 | 34,158 |

以真值对齐 B 为参照，真值对齐 E 净少 3,316 个漏检并净多 12,040 个误报。估计位移下，从 B 背景翻为 E 前景的像素里，有 9,351 个有益纠错、26,820 个有害传播。保留当前背景、两帧原始历史共同支持和外环对应后，分别剩 4,960、15,308 个。局部质量下降门槛将两组都降为零，因此条件 v1/v2 均保留 0% 有益翻转、过滤 100% 有害翻转。

## 局部质量下降门槛消融

条件 v1 要求局部图像细节下降、外环图像对应和两帧历史缺陷响应。条件 v2 还要求历史中心亮度相对外环有同向反差，幅度至少为各自外环的一个标准差。条件 v3 唯一变更是把局部质量下降从强纠错的硬门槛改为诊断项，其余判断沿用条件 v2。初筛前固定的通过条件为相对 B 汇总漏检减少、汇总误报不增。参数组只运行一次。

| 方法（估计位移） | 漏检像素 | 误报像素 | 恢复单帧漏检 | 新增漏检 | 纠正单帧误报 | 新增误报 | 汇总前景 IoU |
|---|---:|---:|---:|---:|---:|---:|---:|
| 单帧 | 685,596 | 1,014,567 | 0 | 0 | 0 | 0 | 37.5654% |
| B、条件 v1、条件 v2（各自） | 685,515 | 1,013,299 | 3,978 | 3,897 | 9,983 | 8,715 | 37.5859% |
| E | 681,680 | 1,025,950 | 13,308 | 9,392 | 24,087 | 35,470 | 37.5522% |
| 条件 v3 | 684,625 | 1,017,023 | 4,868 | 3,897 | 9,983 | 12,439 | 37.5672% |

条件 v3 共触发 6,275 次，造成 4,614 次相对 B 的二值翻转。它保留 E 的 890/9,351（9.52%）有益纠错，过滤 23,096/26,820（86.11%）有害传播。相对 B 或条件 v1/v2，它修复 890 个漏检、增加 3,724 个误报，没有其余方向的翻转。相对 E，它修复 5,516 个漏检、增加 8,461 个漏检，纠正 23,096 个误报、增加 14,169 个误报。

| 来源代理组 | 相对 B 恢复漏检 | 相对 B 新增误报 |
|---|---:|---:|
| A | 221 | 1,667 |
| B | 68 | 1,142 |
| C | 601 | 915 |

条件 v3 未通过开发判据，作为实验消融保留。人工样例中，清晰当前帧漏掉一个历史中仍有图像证据的暗缺陷时，条件 v3 可恢复 9 个像素。把相同输入标为正常暗纹时也会新增 9 个误报。缺乏同向反差或外环错配的样例仍回退保守融合。上述统计是重复派生帧中相关的像素观测，独立物理轨段的缺陷召回、正常轨面的误报负担和端到端时延仍待验证。

## 复现

在候选目录根部安装 `requirements-conditional.txt` 中的依赖后运行以下数据无关检查。检查覆盖条件 v1、v2、v3 的正例、反例和缺失历史行为。

```text
python -B tools/check_conditional_fusion.py
python -B tools/check_conditional_v2.py
python -B tools/check_conditional_v3.py
```

流式接入复用 `rail_motion_v3.MotionFeedback` 的状态。初始化流后，每个输入帧先调用 `step()`，再取同一组基础位移：

```python
import sys
sys.path.insert(0, 'python')
from rail_motion_conditional_v3 import fuse_conditional_v3

probability, diagnostics = fuse_conditional_v3(
    stream.images, stream.raw, stream.edges['base']
)
```

在本地研究工作区，可用以下两条命令重跑冻结批次。完整批次依赖已有的基础运动、前端概率和训练来源划分缓存，运行前检查输入哈希。第二条在核验已冻结的候选概率后打开标注。具体输入目录见两个运行器。

```text
python -B tools/diagnose_conditional_alignment.py --run-id conditional_alignment_NEW
python -B tools/run_conditional_v3_ablation.py --run-id conditional_v3_ablation_NEW
```
