# 单帧基线协议 v0.1

工作题目：基于轻量化深度学习与运动补偿的钢轨表面缺陷实时检测方法研究。

本版只准备数据、实现基线构造与输入检查，没有训练、精度或实时结果。

本页为单帧基线的初始协议。实际结果见[试训](step08_smoke_results.md)、[小规模验证](step09_pilot_results.md)、[完整基线](step10_full_results.md)与[成熟模型对照](step11_mature_results.md)。

## 基线

`small_unet_v1`是已有U-Net架构的小规模配置：RGB输入256×256，二分类，编码深度3，首层16通道，随机初始化，最终输出256×256×2概率图。它不是本项目的新网络。精确参数量由MATLAB执行记录。

成熟对照候选为MobileNetV2–DeepLabv3+，编码器下采样倍数16（可另比较8），最终输出恢复输入尺寸。此对照依赖相应MATLAB模型支持包，尚未实际构造和训练，也未验证K230兼容性。

类别通道顺序固定`background, defect`。后续融合需要第2通道的完整概率，不能把二值掩膜或获胜类别分数当作缺陷概率。

## 输入与标签

- 输入明确为uint8→single/255，网络输入层不再自动重复归一化。
- 作者原图、原标签和下载分卷只读保留。MCnet的JPEG真值先统计解码灰度，前景暂定义为灰度≥128；这是一项明确的处理约定，不是原始标注天生二值。需保存阈值敏感性检查。
- NEU的1位PNG按logical读取；与0/255显示灰度区分。
- 预处理等比例缩小到256窗口内，居中补边，不放大原图；输出有效区域V。训练损失和指标必须排除补边。缩放后缺陷消失的样本须记录，不能从测试集静默删除。
- 全图缩小会损失小缺陷细节，本配置仅作初始统一基线；后续更高分辨率/原生裁剪的比较应控制训练数据、覆盖范围和推理开销。

## 数据划分与防泄漏

优先记录原作者training、validation、人工test和自然real test目录，下载后逐项核对实际数量。NaDiNet论文描述人工2086/885/965和自然165测试，仅作核对参考，不能覆盖与实际文件不符的情况。

自然测试数据不用于调参、阈值选择、归一化或训练；数据审计可以读取结构和哈希，但不以模型效果选择其样本。NEU已查看部分图像与标签，只称外部验证候选，不称完全盲测。

精确重复必须属于同一来源组。跨原始分区的同源/重复先隔离并报告，不随机移动样本以凑数量。物理轨段ID无法恢复时，公开承认独立性限制。所有增强/裁剪/合成帧均继承源图分区。

## 训练前门槛

现已生成`conservative_group_v1`，具体审计与修订数量见[基线准备记录](baseline_preparation.md)。该协议保留原目录字段、按保守来源代理组重划分，并将包含自然测试来源的组整体留出。修订协议与原论文成绩不直接可比。

1. 文件、尺寸、标签和跨分区重复审计通过；冲突条目有可追溯隔离决定。
2. 固定训练/验证/测试名单，记录其SHA-256；解决近重复和可恢复同源组问题。
3. 网络构造、概率维度与标签映射检查通过。
4. 将源码提交号、数据版本、配置、种子、软件与硬件信息写入每次运行。

只有上述准备完成后才启动第一轮训练。性能比较报告缺陷IoU/Dice、Precision/Recall及实际计时，不只报背景占优的像素准确率。随机权重前向检查不构成检测效果或实时性证据。
