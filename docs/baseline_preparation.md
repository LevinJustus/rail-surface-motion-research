# 数据与基线准备

日期：2026年11月14日。

本页介绍数据审查、固定分区与分割基线准备。训练结果见[小样本检查](step08_smoke_results.md)、[小规模训练](step09_pilot_results.md)和[完整基线](step10_full_results.md)。

工作题目：**《基于轻量化深度学习与运动补偿的钢轨表面缺陷实时检测方法研究》**。

## 实际完成

- 建立本地源码项目，保存自行编写的数据获取、校验、审计、预处理、网络构造和序列示例代码。原始分卷、合并包和图像/标签在独立数据目录保留，不覆盖原标签。
- 完整下载MCnet作者数据：116个分卷，共2,512,606,518字节；固定提交`a87a4ca6710346f54870f4ec8dac0a058ffd31df`，各卷Git blob和SHA-256均已校验。
- 实际核查4,101对图像与标签，原目录数量为训练2086、验证885、人工测试965、作者标记的自然测试165。配对及尺寸均匹配，宽/高在300—600像素范围。
- MATLAB已通过输入检查和随机权重网络前向检查；没有开始训练，没有检测精度或实时性结果。

来源：[MCnet作者仓库](https://github.com/zdfcvsn/MCnet)、[作者读取代码](https://github.com/zdfcvsn/MCnet/blob/master/code/dataloaders/rail.py)。数据身份按具体版本与实际文件记录，不仅凭NRSD-CR/NRSD-MN名称判断。

## 数据审计

JPEG标签约0.94%的解码像素不严格等于0/255。源码显式使用灰度≥128映射前景，保留原文件。全集在64、128、192三种阈值下前景总数相同；仍须保留明确的读取约定。

发现154组精确重复RGB，涉及343个文件；其中89组、206个文件跨原始分区。**隔离189个同图同二值标签的冗余副本，本批冲突标注组为0。** 不要与NEU36/37的冲突标注混淆。

原训练/验证和作者标记的自然测试目录也有相同RGB。自然/人工是作者目录类别，不能额外声称逐件形成方式已独立核实。

115个基础编号族中65个跨原始分区。按基础编号、精确RGB和严格感知相似合并成104个保守代理组；包含自然测试来源的组整体留出。这些组不是104根独立钢轨，物理来源独立性仍有限制。

## 固定协议 conservative_group_v1

| 用途 | 图片数 | 代理组数 |
|---|---:|---:|
| 训练 | 1396 | 45 |
| 验证 | 400 | 15 |
| 人工测试 | 454 | 16 |
| 作者自然目录去重测试 | 159 | 28 |
| 与自然测试组潜在相关、整体留出的人工样本 | 1503 | 不另作独立计数 |
| 冗余副本隔离 | 189 | 不另作独立计数 |

自然目录165条减少的6条均为冗余副本，不是按模型表现删样本。活动分区的代理组、基础编号族和精确RGB哈希均不交叉；这不证明物理轨段完全独立。

名单保留原分区、修订分区、代理组与隔离原因。随机种子20261114，名单及其SHA-256保存在`data/splits/`。新协议与原论文划分不同，成绩不能直接与原论文数值作排名。若后来发现新同源关系，应建立新版本并重跑比较，不依模型效果调整分组。NEU已查看部分样本，仅作外部验证候选，不称完全盲测。

## 单帧基线

| 项目 | 已验证配置 |
|---|---|
| 架构 | 已有U-Net的小规模配置，不是本项目新算法 |
| 输入 | 256×256×3；uint8转single/255，输入层不重复归一化 |
| 编码深度 / 首层通道 | 3 / 16 |
| 参数量 | **482,050**，MATLAB实际计数 |
| 输出 | 256×256×2；background / defect通道顺序固定 |
| 权重 | 随机初始化，尚未训练 |
| 预处理 | 等比例缩小、居中补边、不放大；损失和指标须排除补边 |
| 后续成熟对照 | MobileNetV2–DeepLabv3+，支持包和实际构造仍待验证 |

已通过：灰度阈值/1位PNG映射一致、小图不被放大、补边不被当成缺陷、实际训练样本与NEU标签读取、随机网络概率尺寸和概率和检查，以及整理后的序列示例复现。

本机MATLAB报告约31.4 GiB物理内存，当前可用MATLAB GPU数量为0。CPU已完成检查；完整训练成本需要后续小规模训练实测，不能从参数量推出实时FPS。

接口来源：[MathWorks U-Net](https://www.mathworks.com/help/vision/ref/unet.html)、[DeepLabv3+](https://www.mathworks.com/help/vision/ref/deeplabv3plus.html)。网络构造使用MATLAB公共API，相关依赖随对应环境安装。
