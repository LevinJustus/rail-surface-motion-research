# 消融与鲁棒性实验计划

本实验只执行13C2已列出的C5分支，不因13C4无稳定收益而新增更有利的难度、网络或门控参数。配置见fusion_ablation_v1.json及SHA；C4标签已经看过，因此本批属于开发阶段的后续对照。

每帧79个逻辑方法输出：7种观测压力×原8方法；窗口1/5×S/V/GV/GVP；GV去掉4个单独因子；GVP仅换原prior-NCC采样位移；不限长度R；第3帧污染下原8方法加不限长度R。原RGB的12条件、源分区、3检查点、C4各父方法阈值、GC常数均不更改。0.5为主比较，不把各父方法不同校准阈值的差异当模块贡献。

训练先用首种子/36序列，共25596逻辑输出做解析与运行契约；通过后再执行3种子/180验证序列的383940逻辑输出。只复用已冻结原始概率，无模型前向或优化器更新。重复结果按内容SHA引用，独有结果另存float32；预测索引及全部唯一载荷先冻结，再由独立进程打开掩膜。帧数/派生条件不增加独立来源数。

观测压力保持原缺失位，四种每帧增量偏差、两种交替绝对观测扰动、全缺测互不叠加。纯视觉方法输入不变，其输出可引用原C4；全缺测时P回退V、GVP回退GV。prior窗口重新选峰使用同RGB完整NCC候选缓存，视觉位移和质量不因观测变化而重算/改写；记录实际新缓存开销，不声称搜索加速。旧13B/C3/C4文件不修改。

单项门控消融只把命名因子置1，保留可用性、边界拒绝及几何覆盖；不以除以旧零门控的方式恢复因子。prior-alignment分支只换历史采样位移，保持原视觉质量/观测不一致定义，隔离采样变化，不同时设计新门控。基线先验位移等同视觉时，预计该交互输出也相同，如实记录。

不限长度R在每条9帧序列内保留double内部状态，输出才落盘single；不跨序列累计。污染把原第3帧single概率转换为single(1-double(p))，所有方法含S共用；RGB、位移和标签不变，之后原始概率恢复。报告帧4—9相对各自无污染输出的概率差、阈值翻转及额外FP/FN，区分故障注入和自然模型错误。有限窗口恢复不单独构成创新。

执行期间补充的解析说明（2026年11月18日；不改冻结配置）：二元熵满足H(p)=H(1-p)，因此现有熵置信度不能仅凭该因子识别“非常自信但类别完全反转”的原始预测。故障不改变RGB或运动，图像光度与配准质量也不等于分割语义正确性。污染研究将实际测量其传播，不预设门控一定阻止错误；该代数性质不是额外实验证益，也不据此在本实验加入新门控或调参。

评价逐帧统计TP/FP/FN/TN及相对同输入S的四类纠正/新增错误；污染第3帧的S也受相同污染，之后S恢复。所有概率先显式提升double再比较冻结阈值。重复载荷/阈值/参照可缓存计数但保留每个逻辑行。来源统计复用C4的15来源配对抽样索引，所有预定压力和消融均报告，区间只作未多重校正的描述性证据；组件指标基线留在C4，本项不把像素指标改名为物理缺陷事件。

独立审计重算全部计数，固定首来源12条件的帧2/6、全部79方法核查采样和门控；观测选峰另从RGB独立核对。各类输入与评价载荷按独立目录组织。完成C5不代替C6的核心贡献审查、最终保留测试、真实视频或效率测试；当前批次状态见[研究进展](PROGRESS.md)。
