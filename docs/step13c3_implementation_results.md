原始概率和输出分开存储；状态只保留最多三帧原始观测，S不使用历史，R每次在同一窗口重建。重采样明确从当前坐标减去前向位移取历史像素；双跳先合成、只插值一次，并检查中间覆盖。越界和拒绝历史的权重回给当前帧，不把数值占位0当背景。算法接口没有标签/几何/源组/profile输入；评价在预测SHA冻结后另进程运行。这是接口与进程隔离，不宣称操作系统权限沙箱。
