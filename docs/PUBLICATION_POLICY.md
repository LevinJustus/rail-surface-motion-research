# 数据与实验复现

本页汇总数据来源、输入格式和各类实验所需材料。运行命令见[快速开始](START_HERE.md)，方法和阶段结果见[研究进展](PROGRESS.md)。

## 数据来源

钢轨表面缺陷基线使用[MCnet作者仓库](https://github.com/zdfcvsn/MCnet)提供的数据。文件来源、校验值和固定分区分别位于`data/manifests/`与`data/splits/`。

修订分区包含1396张训练图、400张验证图，分别来自45个和15个来源代理组。增强、裁剪及合成序列继承源图分区。代理组用于降低关联样本泄漏风险，其独立性与真实物理轨段独立性分别评估。

按数据作者的授权获取和使用图像与标签，并在使用数据时引用原始来源。第三方软件及数据归属见[THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)。

## 实验输入

| 任务 | 所需输入 | 结果 |
|---|---|---|
| 行为检查与人工挑战 | 脚本生成图像和概率 | 机制检查、人工案例指标 |
| 单帧训练 | 图像、二值掩膜、固定分区与训练配置 | 检查点、训练曲线、验证指标 |
| 受控序列生成 | 选定源图、掩膜与运动配置 | RGB序列、模拟观测和评价几何 |
| 运动反馈与融合 | RGB、原始分割概率、时间戳、可选位移观测 | 融合概率、运动候选及诊断 |
| 独立评价 | 预测、标签；几何诊断另需准确变换 | 像素指标、纠错/新增错误及定位误差 |

算法输入与评价真值采用独立目录。标签和准确变换只在评价步骤使用；模型、阈值和参数依据开发分区确定。

## 文件约定

- Python流式接口使用256×256×3的uint8 RGB和同尺寸缺陷概率。
- 历史概率缓存采用小端float32、列优先；读取后按协议阈值比较。
- 每次实验使用独立的`runs/`子目录，保留配置、输入索引、源码版本和输出摘要。
- 历史批次使用图像、检查点输出及运动缓存。按相应协议准备这些输入后运行批次驱动器，自定义前端可直接接入流式接口。

格式细节见[融合协议](step13c2_fusion_protocol.md)和[v3接口](algorithm_v3_prototype_results.md)。

## 结果文件

`results/`收录逐种子比较、阈值诊断和配准汇总；`docs/evidence/`收录各实验的CSV、检查摘要和聚合图。实验报告注明样本来源、指标口径与适用范围。

`PUBLIC_PROVENANCE.json`记录版本中各文件的来源和校验值，便于追踪文档整理及兼容性调整。历史实验引用的源码SHA对应当次运行版本，当前文件以版本来源记录为准。

## 结果解释

静态验证用于评价分割基线；同图派生序列用于受控运动研究；人工概率用于机制检查；真实视频用于实际采集验证。报告分别呈现这些证据，保留改善与退化，并区分概率缓存处理耗时和完整系统耗时。
