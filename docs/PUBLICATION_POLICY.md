# 发布范围与复现边界

本仓库发布本项目编写的研究代码、固定配置、安全数据元信息、分区名单、实验协议和结果CSV。通过文件校验值追踪来源；修改过的兼容代码在PUBLIC_PROVENANCE.json中说明，不冒充原训练时源码。

论文正文和源稿、Word/PDF、原始图像和标签、下载分卷、生成序列、模型权重、包含原图的图表、完整内部日志与本机配置不纳入版本。数据从原作者入口单独获取，按其授权使用；公开获取不等于有权重新分发。

v0.4.0可包含由本项目自行构造的概率示意SVG，不含原始钢轨图像、真实标签或第三方照片。该人工机制图明确标注范围并包含失败，不作为真实数据成绩。公开接续规则为独立编写的项目说明，不复制内部工作日志或私人协作文件。

每次发布前需核对允许文件名单、来源与哈希、冻结配置依赖、结果口径、相对链接及提交身份。版本需描述变更、验证与局限。未完成的功能不写作已实现；验证选择不冒充最终测试；模拟轨迹不冒充实测编码器或毫米定位；生成时间轴不冒充推理FPS。

当前代码许可证尚未指定，公开可见本身不授予额外再许可；第三方软件与数据仍由其各自条款约束。
