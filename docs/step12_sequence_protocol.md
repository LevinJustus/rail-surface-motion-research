## 2. 原生几何与轨迹

每帧256×256、9帧、时间间隔0.05s。总轨迹预算按预定公式`min(64,H−256−20−6)`源像素确定；本次60源均得到64px预算。取景不缩放、不拼贴、不复制轨面，仅在同一原图范围内采样。原生裁剪相较先前全图缩小的单帧验证有尺度差异，后续必须重新报告该域差异，不能直接沿用此前验证IoU作为序列成绩。

帧索引`t=0…8`的纵向相对位置为64乘以下固定归一化数组：

- 匀速：`[0,.125,.25,.375,.5,.625,.75,.875,1]`。
- 变速：`[0,.03,.10,.22,.40,.60,.80,.94,1]`。
- 停顿及反向：`[0,.2,.4,.4,.4,.3,.2,.1,0]`；包含两段零位移及四段负位移，不强制里程单调累加。

变速最大帧间位移12.8px；无旋转时纵向重叠下界约95%。这是短程高重叠仿真，不冒充真实长距离巡检。停反向的实际往返位置范围小于64px预算，预算不等于实际位移范围或新轨面长度。

取景原点为`[(W−256)/2;(H−256−min(offset)−max(offset))/2]`，即按该预定轨迹的实际完整范围居中，不看标签；绕帧中心`[(256+1)/2;(256+1)/2]`旋转。几何抖动条件加入横移`1.5 sin(2πt/3)`px及旋转`0.7 sin(2πt/5)`度。旋转矩阵没有尺度放大，也不模拟未知的三维轨面视差。

采用MATLAB一基像素中心坐标，`[x_source;y_source;1]=T_k*[x_frame;y_frame;1]`。同一源点的previous→current映射为`inv(T_k)*T_(k−1)`；将previous图重采样到current所需反向采样为`inv(T_(k−1))*T_k`。正纵向相机运动使固定源特征在帧内向负y移动。准确矩阵只保存在评价目录。

## 3. 十二个固定条件

`clean`仅表示不再施加额外的合成图像退化，不保证作者原始静态照片本身完全清晰、无噪声或无照明不均。

| 条件 | 图像/运动 | 模拟里程 |
|---|---|---|
| clean | 匀速、清晰、无几何抖动 | 基础漂移与0.5px量化；不是准确位移输入 |
| variable_speed | 变速、清晰 | 同基础 |
| geometric_jitter | 匀速＋固定横移/旋转 | 同基础；不提供准确横移/旋转 |
| blur_1px | 匀速、1px纵向曝光积分跨度 | 同基础 |
| blur_3px | 匀速、3px纵向曝光积分跨度 | 同基础 |
| persistent_light | 匀速、持续变暗与空间非均匀光照 | 同基础 |
| odom_scale_plus5 | 匀速清晰 | ＋5%比例偏差＋基础漂移/量化 |
| odom_scale_minus5 | 匀速清晰 | −5%比例偏差＋基础漂移/量化 |
| odom_quantization | 匀速清晰 | 3px量化＋基础漂移 |
| stop_reverse | 停顿及反向轨迹 | ＋2%比例偏差＋基础漂移/量化 |
| odom_dropout | 匀速清晰 | 第4、5帧里程缺测，不丢图像 |
| combined | 变速＋几何抖动＋积分模糊＋持续光照 | −2%比例偏差、2px量化，第5帧缺测 |

基础里程公式为`round((scale*s_true+0.6*(t/8)^2)/q)*q`，具有结构化比例/累计漂移/量化，不是实测编码器噪声，也不声称随机噪声。固定seed=20261116用于记录，当前生成过程不进行随机抽样。每个条件要求整个有效观测向量至少有一处非零里程误差，防止再次与真值完全重合。停止或回程中累计漂移仍可能导致非零观测变化，这是待测算法需要面对的模拟误差。

## 4. 曝光积分、光照和标签

模糊图像沿连续分段线性运动轨迹在曝光中心两侧取9个等权子采样并平均，不对清晰帧事后仅做方向无关卷积。匀速1/3px条件的纵向曝光跨度严格为1/3源像素。combined曝光窗口按其最大纵向帧间速度确定，使最大局部跨度约3px；停止/速度折点可能改变实际跨度，各帧实际值逐一记录。横移和角度也随曝光时间线性插值。

每个曝光子采样的全部网格坐标须落在原生图像内；旋转、横摆及曝光边界一起检查。违反边界即停止并保留失败状态，不补边伪造轨面、不按结果换图。当前每帧全部像素有效，无评价补边。

持续光照采用`(0.65+0.05*cos(2πt/8))*(0.75+0.25*x/256)`乘性场，加固定平滑亮带后截断到[0,1]。场在多帧持续存在，不使用逐帧独立随机噪声作为唯一退化。图像为uint8，几何重采样为双线性。

源JPEG掩膜按既有灰度≥128映射为二值，只在曝光中心时刻用最近邻映射到帧。标签不做光照、模糊或软阈值处理；评价目标明确为潜在的中心曝光清晰缺陷轮廓。它不是“曝光后可见区域”或深度真值，严重模糊下这个目标可能难以观察；当前不将模糊效果当作真实裂纹可见性证明。空目标帧或整段均保留并统计，不依前景是否存在重选源或取景。
