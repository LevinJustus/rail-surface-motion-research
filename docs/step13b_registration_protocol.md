# 平移配准比较协议

2026-11-17，在任何实际配准运行前冻结。此阶段只检验配准，不运行分割训练或融合，不提出新的网络贡献。

## 输入与处理

本阶段以第12项不可变输入为基础，采用三个平移对照：里程直接换算（dx=0，dy=负的相邻观测里程增量）、纯视觉NCC、先验约束NCC。仅算法输入目录、无语义序列编号和注册配置进入算法；几何真值由随后独立评价进程读取，分割掩膜不参与本阶段。

固定256×256 RGB，灰度权重0.2989/0.5870/0.1140，除255。前帧中心128×128模板（单基索引65:192），全局候选dx/dy均为−20:20像素；正相关峰，最低NCC为0.2。先验局部窗口dx为−4:4，dy为负观测增量±4，与全局范围取交。峰值内点用一维三点抛物线分别修正，幅度截断±0.5，不跨搜索边界插值。

里程缺失或超范围时，直接里程法记不可用，先验法回退纯视觉；局部NCC低于0.2时同样回退。模板标准差小于1e−6时视觉估计不可用，不伪造零位移。候选、边界峰、使用先验和回退原因逐对保存。未使用标签选择峰或阈值。

两种NCC共用一次完整相关图，因此本实验只能报告共享相关图开销及各自选峰开销，不能据此声称局部搜索具有端到端加速。

## 分区和检查顺序

先执行解析位移/反向/停车/缺测/无纹理契约，再使用训练部分按source_id字典序最前的3个来源、各12条件，共36序列/288相邻对检查链路。之后固定配置执行180验证序列/1440对（15来源×12条件×8对）。不访问保留测试。派生帧和条件不增加独立来源数。

配置中的中性ID名单冻结，带SHA旁文件；所有预测CSV先落盘并计算SHA，随后才开启评价。参数不根据此次验证成绩回调。出现差或无增益结果照常保留。

## 预定评价

准确前到后映射为inv(T_current)×T_previous。采用前帧1至256均匀9×9点阵，按真值映射是否位于后帧[1,256]内固定共同评价点；每种方法均在这些相同点评价。报告中心[128.5,128.5]误差、每对平均网格端点误差EPE、最大误差以及估计落在后帧的比例。不可用估计不纳入有效误差均值，但在覆盖率和失败率分母内保留。

主失败定义为估计不可用或每对平均网格EPE>2像素；附加1、4像素敏感性。按条件报告有效均值/中位数/P95、覆盖率与失败率，并计算等来源宏平均。准确变换含旋转，算法只有平移；中心误差不能代替全图误差。无毫米标定，不报告毫米定位精度。

独立NumPy/Pillow审查全部几何统计和输入SHA，另固定首个验证来源的12条件、每条件第1及第5相邻对（24对）从PNG重算NCC和亚像素选峰。检查缺测回退一致性、全部预测行、配置及源码快照。预期验证里程缺测相邻对75，不以不可用值冒充成功。

## 证据与解释边界

独立重算采用窗口和/平方和与FFT相关，不调用MATLAB相关图输出。运行失败单独保留新目录，不覆盖。数字图表、代码及汇总CSV可供公开；原图、配准图面板、生成帧和原始运行载荷留本地。本阶段结果只描述同图派生高重叠受控序列，不能证明真实视频效果、可靠融合增益、现场定位或K230实时性。NCC是标准比较方法，不以引入运动窗口本身声称首创。

方法来源：[MathWorks normxcorr2](https://www.mathworks.com/help/images/ref/normxcorr2.html)、[官方平移配准示例](https://www.mathworks.com/help/images/registering-an-image-using-normalized-cross-correlation.html)。代码采用R2024b可用的基本接口。
