# 首轮训练方案

工作题目：**《基于轻量化深度学习与运动补偿的钢轨表面缺陷实时检测方法研究》**。

日期：2026年11月14日。方案编号：`stage1_training_v1`。

本页记录首轮训练的固定配置、子集与批次顺序，配套[训练链路检查](step08_smoke_results.md)和[小规模训练结果](step09_pilot_results.md)。

配置与SHA-256保持方案建立时的版本。第08项最终全背景；第09项按本方案完成192次更新，观察到后期前景扩大与指标回退。

## 1. 两级运行预算

| 项目 | 第08项：极小样本试训 | 第09项：小规模训练与验证 |
|---|---:|---:|
| 唯一训练图片 | 8张，来自8个代理组 | 128张，覆盖45个训练代理组 |
| 固定验证图片 | 不使用验证分区，只检查训练8张 | 64张，覆盖15个验证代理组 |
| 每批图片 | 2 | 2 |
| 每张训练图的完整访问轮数 | 4轮 | 3轮 |
| 实际优化器更新目标 | **16次** | **192次** |
| 检查节点（已完成更新数） | 0、4、8、12、16 | 0、64、128、192 |
| 用途 | 排查数据、梯度、更新和模型保存问题 | 观察学习趋势、验证表现及CPU耗时 |

这两个阶段都是工程排错和初始观察，不用于论文性能结论。16次更新只是有限的链路检查预算，不承诺模型已拟合，也不以达到某个Dice作为硬门槛。完整训练方案在试训耗时与结果出来后另行固定。

两个阶段均从相同种子的全新随机初始化开始，小规模阶段不默默接着极小集模型训练。每轮固定子集中的图片均访问一次，无放回打乱；因此当前更新次数可明确对应轮数，不把重复抽样次数当作独立样本数。

## 3. 损失函数的确切含义

对图像i，令缺陷真值为y、有效区域为V、缺陷概率为p，所有求和只在该图有效像素内进行。

\[
L_{BCE,i}=-\frac{\sum V[y\log p+(1-y)\log(1-p)]}{\sum V},
\]

\[
L_{Dice,i}=1-\frac{2\sum Vpy+10^{-6}}{\sum Vp+\sum Vy+10^{-6}}.
\]

- 图中存在有效前景时，`L_i = 0.5 × BCE_i + 0.5 × DiceLoss_i`。
- 图中没有有效前景时，`L_i = BCE_i`，不将正常图权重无意减半，也不静默删样本。
- 批损失是各图L_i的平均，不让补边大小或原图尺寸决定样本权重。
- 有效区域为空时直接报数据错误；V必须同时进入BCE与Dice的所有求和。

配置里的`bce_weight_positive_target`表示**非空目标图的损失分量权重**，不是给每个前景像素再乘0.5。数值实现优先用两类softmax前logits的稳定log-softmax计算BCE，避免直接对0概率求对数；Dice使用缺陷概率，不能对softmax后的概率再套一次sigmoid。

当前数据没有完整正常图像集，本实验不额外手挑背景裁剪加入训练。空目标行为将在第08项以受控输入核验；即使通过，也不能声称已验证真实正常巡检误报率。

## 4. 子集与顺序如何固定

父划分保持`conservative_group_v1`不变。候选只取其`assigned_split=training`或`validation`，不读取保留测试图像或标签。

1. 用种子、协议版本、父划分SHA-256及组ID计算哈希，固定组顺序。
2. 用同样上下文与样本ID哈希固定组内顺序。
3. 按组轮流无放回取样，分别得到128张训练图、64张验证图；不按缺陷大小、图像质量或预测表现挑图。
4. 极小集8张取训练128清单的前8张，已核验来自8个不同代理组。
5. 每轮按种子、配置阶段、轮号和ID哈希打乱；验证始终按固定64张的清单顺序推理，不做随机重采样。

部分合法训练样本ID带有`artificial_test/`或`validation/`前缀，那是原作者目录名。访问保护必须核对**修订清单中的assigned_split**，不能根据ID前缀判断泄漏。

| 冻结文件 | 作用 |
|---|---|
| `configs/training_stage1_v1.json` | 本轮参数与保存规则 |
| `data/splits/pilot_subset_v1.json` | 8/128/64固定子集 |
| `data/splits/stage1_batch_schedule_v1.json` | 每次更新对应的图片ID及固定验证顺序 |
| 上述同名`.sha256` | 按实际UTF-8文件字节校验 |
| `docs/evidence/stage1_plan_check.json` | 数量、分组隔离、轮内覆盖及哈希核验结果 |

执行`python tools/prepare_stage1_plan.py --check`可以复核现有文件；它只读取元数据，不训练，也不打开原始图像。生成器拒绝覆盖不同的已固定计划。

## 5. 日志、模型保存与指标

每次更新记录总损失、BCE/Dice分量、裁剪前梯度范数、裁剪系数、样本ID、有效像素数和真实耗时。非有限损失或梯度属于运行错误，停止并保存诊断，不计作成功更新。

极小集保存更新0、8、16的状态，仅检查训练8张。配置中“完整固定64张验证”仅适用于pilot，极小集阶段不读取这64张。

pilot在更新0、64、128、192评估全部固定验证集，每32次更新保存恢复点，保存初始与最终模型。checkpoint必须包含网络及其状态、Adam一/二阶矩、已完成更新数、下一批位置、随机状态、所有配置和数据哈希、源码版本、通道顺序及环境。

- `global_update`指**已完成的优化次数**；保存的是完成该次更新后的状态。
- `next_schedule_position = global_update + 1`，完成N次更新后可为N+1结束标记。恢复时不重复或跳过批次，也不重置Adam迭代计数。
- 模型重新加载后，在固定输入上的概率最大绝对差目标不超过1e−6。
- 首轮主要报告最终192次更新的模型及完整验证曲线。另保存验证诊断最佳点，候选只来自预设验证点，包括更新0；若初始模型最好，如实标明“未训练参考最好”，不冒充已训练成果。
- 最佳点按验证集汇总缺陷IoU最高、再按有效区损失更低、最后按更新数更早决定。合法分母为0产生的IoU NaN不参与最佳比较；若全为NaN，则记录`best_unavailable`并保留last。非有限预测概率/验证损失则属于数值错误。

验证输出包括累计TP/FP/FN/TN后的micro缺陷IoU、Dice、Precision和Recall，以及图像/组层面的描述指标。分母为0时记NaN并报告数量，不默认为1抬高均值；同时记录真值/预测前景比例，显式指出“全部预测背景”等退化。

可视化固定取极小集8张和验证清单前8张，显示原图、真值、缺陷概率和阈值掩膜，避免事后只选好看的例子。验证只有15个代理组，首轮用于排错与观察趋势，不作显著性、泛化或实时性结论。
